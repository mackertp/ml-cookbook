# Networking 101

[Computer Networks](https://en.wikipedia.org/wiki/Computer_network) are best understood at a basic level, as they can grow increasingly more complicated through required protocols and system configurations. In the simplest terms, a computer network is where multiple machines communicate with each other to achieve a task. 

Through a few layers of networks, we can start to build complex systems such as the internet. The general way the internet works is by connecting your physical device (e.g. laptop) to a WiFi, mobile, or lan-connected network. This initial connection then communicates with a larger network built by your Internet Service Provider (ISP). For another useful application on a slightly smaller scale, view the cdns notebook.
