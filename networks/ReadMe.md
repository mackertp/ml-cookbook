# Networking 101

[Computer networks](https://en.wikipedia.org/wiki/Computer_network) allow multiple computers and systems to communicate with each other and exchange information. As organizations grow, their connections become more sophisticated and require additional protocols, security measures, and configurations to ensure that data is transmitted reliably and securely.

One example of a network at scale is a Content Delivery Network (CDN). CDNs are distributed networks of servers that cache and deliver content from locations closer to the user. Instead of requests traveling back to a single origin server, content is served from strategically placed nodes around the world, improving performance and reducing latency.

For most business users, it is not important to understand how every packet reaches its destination, but that systems are able to communicate and share data to accomplish a common goal (usually efficiency). The Integrations folder explores these concepts with real examples of how major software platforms expose secure APIs to allow external systems to retrieve, create, update, and delete data programmatically.

The good news is that systems can talk to each other; the bad news is that they usually expect you to learn their language.
